# UPI Analytics Dashboard

Professional Power BI dashboard analyzing India's digital payment ecosystem (2016-2025).

## 📊 Project Overview
Interactive analytics dashboard showcasing UPI transaction trends, app market share, bank performance, and volume forecasts with real-time insights.

## ✨ Features

### 4 Interactive Charts
- **UPI Volume Growth** - Line chart showing transaction volume from 2016-2026
- **App Share by Volume** - Top 10 payment apps by transaction volume
- **Volume Forecast vs Actual** - Column chart comparing actual vs predicted volumes
- **Bank Performance** - Top 10 performing banks by transaction volume

### 3 KPI Cards
- **Avg Ticket Size:** 211.95K
- **YoY Growth %:** 216.83K
- **Total Banks Live:** 39K

### Interactive Features
- Top 10 filtering on app and bank performance charts
- Dynamic data refresh capability
- Drill-down analytics ready

### Professional Design
- Dark navy theme (#0D1B2A) for enterprise look
- Colorful KPI cards (Pink, Purple, Peach)
- 1920×1080 Full HD canvas
- Key Insights summary box with actionable findings
